# Analysis and Prediction of Used Car Prices
The dataset explored in this project contains over 90,000 entries of used car data scraped from the British market. The aims are to examine how different car features influence the car price, and to predict the car price. Please refer to the [notebook](https://github.com/y-alzahrani/used-car-prices-analysis/blob/main/notebook.ipynb) to view the results.

*Note: The plots were made using Plotly, but since GitHub does not support interactive plots they were rendered as static images.*
